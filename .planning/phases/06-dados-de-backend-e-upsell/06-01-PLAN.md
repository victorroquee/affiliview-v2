**New function 1 -- computeBackendProducts (for BKND-01):**

```typescript
export function computeBackendProducts(rows: TransactionRow[]): UpsellProductRow[]
```

- Filter `rows` to payments only (use `isPayment`) where `upsellNo > 0`
- Group by `productName`
- For each group: count quantity, sum grossAmount, sum netAmount
- Classify each product name using this logic:
  - Match against regex patterns: `/^up\s?1\b|^up\(1\)/i` -> "up1", `/^up\s?2\b|^up\(2\)/i` -> "up2", `/^up\s?3\b|^up\(3\)/i` -> "up3", `/^down\s?1\b/i` -> "down1", `/^down\s?2\b/i` -> "down2", `/^down\s?3\b/i` -> "down3", otherwise "other"
- Compute `contributionPct` = (product gross / total upsell gross) * 100
- Sort by gross descending
- Return array of `UpsellProductRow`

**New function 2 -- computeAffiliateUpsells (for BKND-02, BKND-03):**

```typescript
export function computeAffiliateUpsells(
  filteredRows: TransactionRow[],
  affiliateName: string
): AffiliateUpsellBreakdown
```

- Filter `filteredRows` by `affiliate.trim() === affiliateName` and `isPayment`
- Separate into front (upsellNo === 0) and upsell (upsellNo > 0) groups
- frontSalesCount = front group length
- totalNet = sum netAmount of ALL payments (front + upsell) for this affiliate
- totalAOV = frontSalesCount > 0 ? totalNet / frontSalesCount : 0
- Group upsell rows by productName: for each, count quantity, sum grossAmount
- For each upsell product: aovContribution = frontSalesCount > 0 ? gross / frontSalesCount : 0; aovContributionPct = totalAOV > 0 ? (aovContribution / totalAOV) * 100 : 0
- Sort upsells by quantity descending
- Return `AffiliateUpsellBreakdown` object

**New function 3 -- computeTopProductPerAffiliate (for BKND-04):**

```typescript
export function computeTopProductPerAffiliate(
  allRows: TransactionRow[]
): Map<string, string>
```

- Filter allRows to payments only (isPayment)
- Determine 7-day window: find max date in dataset, windowStart = maxDate - 6 days (same logic as computeAffiliateRankings)
- Filter to rows within the 7-day window where upsellNo === 0 (front sales only)
- Group by affiliate name, then within each affiliate group by productName
- For each affiliate, find the productName with the highest count
- Return Map of affiliateName -> topProductName
- Strip M-prefix from product names for display: apply `productName.replace(/^M[123]\s*/i, "")` to the result value
