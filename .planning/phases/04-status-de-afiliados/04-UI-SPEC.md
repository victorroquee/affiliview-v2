#### 1. `tier-badge.tier-emrampa` (CSS class addition)

- Pattern: matches `.period-bar-presets` / `.period-btn` button set
- Three tabs: "Todos" | "Ativos" | "Em Rampa" | "Inativos"

- Inactive tab: `border: 1px solid var(--border)`, `color: var(--text-2)`, transparent background
- Border-radius: 20px (pill shape, matching period buttons)
- Font: 12px weight 500

- Placement: in `.table-header` row, right-aligned, above the ranking table

#### 3. Summary badge row (Affiliates page header)
- Pattern: inline flex row with `gap: 8px`
- Three badges using `.tier-badge` classes: "4 Ativos" (tier-ativo), "8 Em Rampa" (tier-emrampa), "9 Inativos" (tier-inativo)
- Placement: below the `h2` "Resultados por Afiliado" heading in `.section-header`
- Font: 11px weight 600 (badge interior)

#### 4. New KPI card — "Inativos no Periodo"
- Reuses existing `KPICard` component
- Props: `icon={UserX}` (lucide-react), `label="Inativos no Período"`, `value={count}`, `info={tooltip text}`
- Color prop: no color override (neutral — not a failure metric)
- Placement: 5th card in `.kpi-grid-4` Atividade section — expand grid to 5 columns OR start new KPI group row
- Grid decision: add as a 5th card — update `.kpi-grid-4` to `.kpi-grid-5` rule in CSS OR use `.kpi-grid` (5-col) if Atividade section is refactored. Use whichever avoids layout breakage.

#### 5. Tooltip/sub-text on "Afiliados Ativos" KPI card
- Pattern: `.kpi-card-sub` below `.kpi-card-value`
- Content: "X Ativos · Y Em Rampa · Z Inativos"
- Font: 11px, weight 400, color `var(--text-3)`
- Separator: ` · ` (middle dot with spaces)

#### 6. "Ultima venda" sub-label in inactive affiliate rows
- Placement: below affiliate name in the table row Name cell
- Font: 11px, weight 400, color `var(--text-3)`
- Content: "Ultima venda: X dias atrás" (or "Hoje" / "Ontem" for 0-1 day gaps)

## Interaction Contract

### Status Filter Tabs (Affiliates page)

- Default state: "Todos" tab active — full ranking table visible
- On click "Ativos": filter table rows to Tier 1 / Tier 2 / Tier 3 / Ativo only
- On click "Em Rampa": filter table rows to Em Rampa only
- On click "Inativos": filter table rows to Inativo only; show "Ultima venda" sub-label on each row
- On click "Todos": clear filter, show all
- Filter is UI-only state (`useState`) — no URL change, no persistence
- Active tab renders with dark fill (`.period-btn.active` pattern)
- Tabs always visible regardless of which filter is active

### Summary Badge Row (Affiliates page)

- Read-only display — badges are not clickable
- Counts update reactively with ranking data
- Placed below `h2` in `.section-header`, as a flex row with `gap: 8px`

### "Afiliados Ativos" Dashboard KPI (fixed count)

- Value: count of Tier 1 + Tier 2 + Tier 3 + Ativo affiliates (from `computeAffiliateRankings`)
- Sub-text below value: "{X} Ativos · {Y} Em Rampa · {Z} Inativos"
- Hover on info icon shows updated tooltip (see Copywriting Contract)
- No click interaction

### "Inativos no Periodo" Dashboard KPI (new)

- Value: count of Inativo affiliates
- Hover on info icon shows tooltip
- No click interaction (deep linking to Affiliates page is deferred)
- Color prop: none (neutral display)

### Em Rampa in Ranking Table

- Em Rampa rows appear after all Tier + Ativo rows, before Inativo rows
- Sort order within Em Rampa: descending by gross revenue (same as other tiers)
- Badge: `.tier-badge.tier-emrampa` amber pill
- No other row-level changes
